# Google Autocomplete — מצב הפרויקט

## מטרת הפרויקט

המערכת קוראת מאגר קובצי טקסט ומחזירה עד חמש השלמות למשפט שהמשתמש מקליד. התאמה מתבצעת ללא תלות באותיות גדולות/קטנות, בפיסוק וברווחים מיותרים, ומאפשרת עד תיקון תו אחד לפי כללי הניקוד של המטלה.

## מבנה האלגוריתם

המערכת מחולקת לשני שלבים:

- **Offline:** טעינת שורות מהמאגר, נרמול ובניית אינדקסי unigram, bigram ו-trigram.
- **Online:** נרמול קלט, חיפוש exact תחילה, חיפוש fuzzy רק אם חסרות תוצאות, דירוג והחזרת Top-5.

ה־matcher בודק משפט מועמד יחיד ומחזיר ציון או `None`. מנגנון ה־autocomplete אחראי על בחירת מועמדים ועל המיון הסופי.

## הפעלה ובדיקות

מהתיקייה `project`:

```powershell
python -m unittest discover -s tests -v
```

ממשק ה־CLI, טעינת `Archive.zip` ו־`get_best_k_completions(prefix)` יחוברו לאחר מיזוג רכיבי loader/indexer/autocomplete מהענפים המתאימים.

## מגבלות ומדידות

בבדיקה הנוכחית של המאגר המלא, בניית האינדקס ארכה בערך 51 שניות והשתמשה בכ־2.56GB RAM. קלטים קצרים מאוד (1–3 תווים) מחזירים הרבה מועמדים ולכן איטיים יותר; שיפורים מתוכננים כוללים Top-5 מחושב מראש לקלטים קצרים וטעינת אינדקס שמור.
